Cara Kerja SVM

Setelah membaca dan memahami pengertian SVM dan Konsep Dasarnya, sekarang temen-temn bisa memahami cara kerja algoritma ini dalam mengklasifikasikan data.

1. Membangun Klasifikasi SVM

*Bagi Data Anda
Sama seperti model machine learning lainnya, langkah pertamanya adalah membagi data menjadi data latih (train) dan data uji (test). Sebelum masuk ke pemodelan svm, sebaiknya lakukan dulu eksplorasi data awal (EDA). Meskipun tidak wajib secara teknis, langkah ini penting supaya kamu tahu kalo ada data yang kosong atau milai yang menyimpang (outlier)
*Menghasilkan dan mengevaluasi model
Import modul SVM (misalnya dari scikit-learn), latih model dengan data latih, lalu prediksi data uji. Evaluasi hasilnya menggunakan akurasi serta metrik tambahan seperti precision, recall, dan f1-score.
*Penyetelan Hyperparameter
Performa model SVM bisa ditingkatkan dengan menyetel hyperparameter. Kombinasi terbaiknya seperti jenis kernel, nilai regularisasi(C), dan Gamma dapat dicari menggunakan grid search dam cross-validation

2. Contoh Penggunaan SVM

Klasifikasi teks & analisis sentimen
Memilah ulasan pelanggan menjadi positif atau negatif serta menyaring email spam, karena data teks memiliki banyak fitur (dimensi tinggi).
Pengenalan wajah & citra
Membedakan wajah dari latar belakang, mengenali tulisan tangan, mendeteksi manipulasi gambar, atau mengklasifikasikan jenis objek/daun berdasarkan fitur visual.
Kesehatan & bioinformatika
Membantu diagnosis medis, klasifikasi ekspresi gen, atau identifikasi pola penyakit berdasarkan data klinis maupun citra medis.
Keuangan & peramalan
Mendeteksi penipuan transaksi (fraud) atau memprediksi nilai numerik seperti jumlah pendaftar maupun tren data menggunakan Support Vector Regression (SVR).

3. Implementasi sederhana SVM

Kode tersebut merupakan contoh implementasi sederhana Support Vector Machine (SVM) untuk menyortir kualitas produk menjadi Grade A atau Grade B berdasarkan bobot (gram) dan skor kematangan.

Pada bagian awal, kode mengimpor pustaka numpy untuk mengolah data numerik dan SVC dari scikit-learn untuk membangun model klasifikasi SVM. Selanjutnya disiapkan data fitur X berisi enam sampel [bobot_gram, skor_kematangan] serta label target y dengan nilai 1 untuk Grade A (layak jual utama) dan 0 untuk Grade B (sortir/olahan).

Setelah data siap, model dibuat menggunakan SVC(kernel="linear", C=1.0) untuk mencari batas pemisah garis lurus lalu dilatih dengan model.fit(X, y). Terakhir, model memprediksi data_baru ([125, 8.2] dan [75, 4.2]) melalui model.predict(data_baru), kemudian perulangan for mengubah label 1 dan 0 menjadi status "Grade A" atau "Grade B" sekaligus mencetak hasilnya ke layar.
